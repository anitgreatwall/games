# 颈椎康复训练 · Cervical Rehab Game

一个基于**摄像头头部姿态追踪**的颈椎康复训练网页应用。用头部动作完成临床循证的颈椎训练，全程缓慢、可控、在无痛范围内进行。原版弹幕躲避游戏（DODGE FIRE）作为可选的「街机模式」保留，并加了进入前的安全提示。

> 🌐 在线访问
> - GitHub Pages：https://anitgreatwall.github.io/games/
> - Vercel（海外镜像，国内可能被墙）：https://cervical-rehab-game.vercel.app

整个应用是**单个 HTML 文件**（[`camera-dodge-game.html`](camera-dodge-game.html)），无需安装、无需后端，浏览器打开即用。

---

## ✨ 功能

- **真·颈椎角度追踪**：用 MediaPipe FaceLandmarker 解算头部姿态，映射到三个临床平面
  - 偏航 yaw → **旋转**（左右转头）
  - 俯仰 pitch → **屈/伸**（低头/抬头）
  - 翻滚 roll → **侧屈**（耳朵向肩膀靠）
- **校准**：先采集中立位，再测量个人**无痛活动范围**，所有训练目标设为实测范围的 70–80%，绝不越界。
- **安全筛查**：患者模式下做红旗征问卷（外伤、眩晕、上肢放射痛、骨质疏松等），命中后锁定高刺激模块并采用保守剂量。
- **五个循证训练模块**
  | 模块 | 训练目标 | 依据 |
  |---|---|---|
  | 🌅 热身 | 各方向小幅缓慢活动 | 训练前预备 |
  | 🧭 活动度 ROM | 缓慢转向目标并保持，奖励平滑、限制过快 | Sarig-Bahat VR 运动学 |
  | 📐 收下巴 CCF | 深层颈屈肌，保持 10s × 多次 | JOSPT 2017 颈痛指南 |
  | 🎯 本体感觉 | 闭眼回到中立位，测关节定位误差 (JPE) | Treleaven 感觉运动控制 |
  | 👁️ 凝视稳定 | 注视固定点缓慢转头，眼-头协调（含头晕自检） | Treleaven |
- **节奏与剂量**：组次/保持/休息计时；**速度上限**会拦截过快的甩头动作（达不到康复目的且有风险）。
- **客观指标 + 趋势**：每次训练把活动度峰值、动作平滑度、关节定位误差、达标保持次数存到本地（localStorage），训练报告显示本次结果并与上次对比。

## 🩺 循证基础

- **颈椎活动度正常值** — 目标按个人实测无痛范围的百分比设定，而非套用绝对值。
- **JOSPT 2017《颈痛临床实践指南》** — 颅颈屈曲 (CCF) / 深层颈屈肌训练。
- **Sarig-Bahat 交互式 VR 颈椎运动学** — 以活动度、速度、动作平滑度、准确性作为评估与训练指标。
- **Treleaven 颈椎感觉运动控制** — 关节定位误差、凝视稳定、眼-头协调训练。
- **剂量与安全共识** — 约 10 秒保持 × 约 10 次、配休息、循序渐进、无痛范围。

## 🎮 使用方法

1. 用 **Chrome / Edge** 打开在线地址（摄像头需要 HTTPS，已自动提供）。
2. 首页选择 **康复训练**（或 **街机模式** 娱乐）。
3. 选择身份：**保健/防手机颈** 或 **颈痛/康复期**（后者会做安全筛查）。
4. 先 **校准**（中立位 + 无痛活动范围），再选模块训练。
5. 训练结束查看报告与趋势。

> 首次进入会联网下载头部姿态模型（约几秒）。离线或不支持时，角度训练不可用，会有提示。

## 🛠️ 技术

- 纯前端单文件：HTML + CSS + 原生 JS（无构建步骤）。
- 头部姿态：[`@mediapipe/tasks-vision`](https://www.npmjs.com/package/@mediapipe/tasks-vision) 的 FaceLandmarker（CDN 加载）。
- 数据持久化：`localStorage`。
- 部署：GitHub Pages（`main` 分支根目录）/ Vercel（[`vercel.json`](vercel.json) 根路径重写）。
